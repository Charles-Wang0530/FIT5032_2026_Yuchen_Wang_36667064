# MindBridge

MindBridge is a responsive Vue 3 web application for a community mental health charity. It provides an approachable first step through anonymous mood check-ins, practical resources, community events and role-aware account experiences.

## Run locally

```sh
npm install
npm run dev
```

## Current development stage

The first milestone establishes the Vue application, responsive route structure and the bright yellow-and-blue visual system. Dynamic data, validation, authentication, role access, ratings and security controls will be added in the following planned milestones.
